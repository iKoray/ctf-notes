# ctf-notes

This repository is a personal collection of scripts and structured notes used for Capture The Flag competitions, security labs, and hands on offensive security practice.

It serves as a growing reference for enumeration, analysis, and exploitation workflows. Content is added and refined over time as existing notes are migrated and new material is developed through use.

---

## Purpose
- Centralize commonly used scripts and commands
- Maintain concise, high signal tool notes
- Provide quick reference during CTFs and labs

---

## Current Contents

### Scripts
- `extract_metadata_from_stream.py`
  Outputs clean metadata to CSV for analysis.

### Notes
- `nmap.md`
  Focused Nmap reference for CTF usage.
